# 隐私与 Cookie

本说明适用于 artalk.js.org 上的 Artalk 官网和文档。网站会在浏览器中保存语言和配色等偏好。如果你发表评论，评论服务会收到评论内容、你填写的个人资料、IP 地址和浏览器的 User-Agent 信息。

## 访问统计

我们使用 Microsoft Clarity 了解读者访问了哪些页面、在哪里点击或滚动。微软会用这些数据生成热图和访问回放。评论区内容在回放中会被遮盖，分析 Cookie 默认禁用。如果浏览器启用了全球隐私控制（Global Privacy Control），本站会跳过 Clarity。详见[微软隐私声明](https://privacy.microsoft.com/zh-cn/privacystatement)。

## 广告

Artalk 使用 Google AdSense 获取项目维护收入。启用广告后，Google 及其广告合作伙伴可能使用 Cookie 等标识符投放广告、衡量广告效果，也可能根据你访问本站和其他网站的记录展示个性化广告。详见 [Google 如何使用合作伙伴网站的信息](https://policies.google.com/technologies/partner-sites?hl=zh-CN)。

当页面显示同意提示时，你可以接受、拒绝或逐项设置。之后可以通过 Google 在页底显示的隐私设置链接更改选择。你也可以在 [我的广告中心](https://myadcenter.google.com/) 管理 Google 个性化广告偏好，或在 [YourAdChoices](https://optout.aboutads.info/) 管理第三方广告偏好。

如有与本站隐私相关的问题，请联系 [artalkjs@gmail.com](mailto:artalkjs@gmail.com)。
